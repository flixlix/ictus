ictus is a headless as-you-type mask for a plain <input>. Use it for day-month-year dates (`apply` / `applyPaste`, or React `useDateFieldMask`) and for 24-hour times (`ictus/time`: `applyTime` / `bindTimeMask`, or React `useTimeFieldMask`). Attach it to an existing text input; keep the host app’s UI.

- custom or design-system Input wrappers used for dates or times

When to use a date input mask

Good fit for birthdates, expiry dates, start/end dates, or clock times in a single text input that should format while someone types. Works with your existing input styles, in vanilla JS/TS or React.

  • Dates: dd.mm.yyyy, dd/mm/yyyy, dd-mm-yyyy, plus mm/dd/yyyy and yyyy-mm-dd via mode
  • Times: HH:mm or HH:mm:ss via ictus/time
  • React: useDateFieldMask and useTimeFieldMask

Size and speed

ictus is tiny and does a lot. The date core is 2.6 kB gzipped, time is a separate 2.3 kB entry, and the React hooks add 0.9 kB on top.

Import Minified Gzipped
ictus 7.0 kB 2.6 kB
ictus/time 5.7 kB 2.3 kB
ictus/react (excluding React, core, time) 2.9 kB 0.9 kB

It’s fast, too. Each keystroke takes about 0.2 microseconds. Your screen redraws every 16 milliseconds, so ictus could handle around 80,000 keystrokes before you’d see a single frame of delay.

API

Most apps need one call: bindDateMask / bindTimeMask for a plain input, or useDateFieldMask / useTimeFieldMask in React. The rest are pure functions on strings, for when you handle events yourself.

apply

The core of ictus. Pass the current value, the selection, and the key that was pressed, and get back the next value and caret. Unknown keys and rejected digits leave the value as it was. Backspace and Delete also strip any non-mask characters from the result. If text is selected, Backspace and Delete remove it and a digit replaces it. 

import { apply } from "ictus";

apply({
  value: "1",
  caret: 1,
  key: ".",
  separator: ".", // default
});
// { value: "01.", caret: 3 }
value
The current masked string.
caret
Where the selection starts, or the caret position if nothing is selected.
selectionEnd?
Where the selection ends. Defaults to caret.
key
The KeyboardEvent.key value: a digit, ., /, -, Backspace, or Delete.
separator?
The single character to write between groups. Defaults to ".".
mode?
Field order: "dmy" (default), "mdy", or "ymd".
step?
How much ArrowUp and ArrowDown change the group under the caret. Defaults to 0, which ignores arrows. isDateMaskKey returns false for arrow keys, so handle them yourself when you turn this on: 
const step = 1;
if (
  isDateMaskKey(event.key) ||
  (step > 0 && (event.key === "ArrowUp" || event.key === "ArrowDown"))
) {
  event.preventDefault();
  apply({ value, caret, key: event.key, step });
}

applyPaste

Like apply, but for pasted text. It understands 11/12/2026, the dotted and dashed versions, bare digits like 11122026, and ISO 2026-12-11, which it reorders to day-month-year. 

import { applyPaste } from "ictus";

applyPaste({
  value: "",
  caret: 0,
  pasted: "2026-12-11",
});
// { value: "11.12.2026", caret: 10 }

parseDate

Turns a finished value into a Date at local midnight. Anything partial or impossible, like 31 February, returns undefined. Any of ., /, and - works as the separator. Pass min and max to also reject days outside a range. 

parseDate("11.12.2026"); // local Date
parseDate("11/12/2026"); // same
parseDate("11.12.2026", { min, max });
parseDate("32.01.2020"); // undefined
parseDate("31.02.2020"); // undefined
parseDate("11.12");      // undefined




    
dateStatus

    

      Tells you what feedback to show. Returns "empty", "incomplete",
      "invalid" (complete, but not a real date), or "valid".
    

    

      
dateStatus("");           // "empty"
dateStatus("11.12");      // "incomplete"
dateStatus("31.02.2020"); // "invalid"
dateStatus("11.12.2026"); // "valid"

      
    


    
formatDate

    

      The reverse of parseDate. Writes a Date as
      dd.mm.yyyy from its local day, month, and year, with the separator you pass.
    

    

      
formatDate(new Date(2026, 11, 11));
// "11.12.2026"

formatDate(new Date(2026, 11, 11), "/");
// "11/12/2026"

      
    


    
isDateMaskKey

    

      Returns true for keys apply handles. Check it in
      keydown before calling preventDefault, so arrows, Tab, and
      shortcuts keep working. Block other printable keys on the input yourself (the demos here
      do) so letters never land in the field value.
    

    

      
if (!isDateMaskKey(event.key)) {
  if (
    event.key.length === 1 &&
    !event.ctrlKey &&
    !event.metaKey &&
    !event.altKey
  ) {
    event.preventDefault();
  }
  return;
}
event.preventDefault();

      
    


    
bindDateMask

    

      The simplest way to use ictus without a framework. It listens for typing and pasting on an
      input, applies the mask, and keeps the caret in place. Call the function it returns to
      remove the listeners.
    

    

      
import { bindDateMask } from "ictus";

const unbind = bindDateMask(input, { separator: "." });
// later: unbind();

      
    


    
applyTime / applyTimePaste

    

      The time mask mirrors apply. Default shape is HH:mm with separator
      :. Pass precision: "second" for HH:mm:ss. Users may type
      :, ., or - to commit a group; the field always writes
      the configured separator.
    

    

      
import { applyTime, applyTimePaste } from "ictus/time";

applyTime({ value: "", caret: 0, key: "9" });
// { value: "09:", caret: 3 }

applyTimePaste({ value: "", caret: 0, pasted: "14:30" });
// { value: "14:30", caret: 5 }

      
    


    
parseTime / timeStatus / formatTime

    

      parseTime returns a TimeValue
      ({ hours, minutes, seconds }) for a complete clock-valid mask, or
      undefined. With minute precision, seconds is 0.
      timeStatus classifies like dateStatus.
      formatTime accepts a Date or TimeValue.
    

    

      
parseTime("14:30");
// { hours: 14, minutes: 30, seconds: 0 }

timeStatus("24:00"); // "invalid"
formatTime({ hours: 9, minutes: 5, seconds: 0 }, "."); // "09.05"

      
    


    
bindTimeMask

    

      Same wiring as bindDateMask, for time fields.
    

    

      
import { bindTimeMask } from "ictus/time";

const unbind = bindTimeMask(input, {
  separator: ":",
  // precision: "second",
});

Vanilla <input>

    

      Use bindDateMask. If the value lives outside the input, pass
      getValue and setValue. To handle events entirely yourself, call
      apply and isDateMaskKey directly.
    

    

      
import { bindDateMask } from "ictus";

const input = document.querySelector("input");
const unbind = bindDateMask(input, {
  separator: ".",
  onValueChange: (value) => console.log(value),
});

// later: unbind();

      
    


    
useDateFieldMask

    

      Import from ictus/react. React is an optional peer dependency, so the core stays
      dependency-free. Spread inputProps onto your input and the hook handles typing,
      pasting, and the caret.
    

    

      
parsed

      
The local Date, or undefined until the value is complete and valid.

      
status

      
The same result as dateStatus.

      
isoValue, hiddenInputProps

      
The date as YYYY-MM-DD, ready to submit with a form.

    

    

      Pass value and onValueChange for a controlled field, or
      defaultValue for an uncontrolled one. onParsedChange fires when the
      date itself changes. min and max work as in
      parseDate.
    

    

      
import { useState } from "react";
import { useDateFieldMask } from "ictus/react";

function DateInput() {
  const [value, setValue] = useState("");
  const { inputProps, hiddenInputProps, isoValue, parsed, status } =
    useDateFieldMask({
      value,
      onValueChange: setValue,
      onParsedChange: (date) => console.log(date, isoValue),
    });
  return (
    <>
      <input {...inputProps} />
      <input name="date" {...hiddenInputProps} />
    </>
  );
}

      
    


    
useTimeFieldMask

    

      Same shape as useDateFieldMask, for time. isoValue is always
      colon-separated (HH:mm or HH:mm:ss). parsed is a
      TimeValue or undefined.
    

    

      
import { useTimeFieldMask } from "ictus/react";

function TimeInput() {
  const { inputProps, hiddenInputProps, parsed, status } = useTimeFieldMask({
    onParsedChange: (time) => console.log(time),
  });
  return (
    <>
      <input {...inputProps} />
      <input name="time" {...hiddenInputProps} />
    </>
  );
}
